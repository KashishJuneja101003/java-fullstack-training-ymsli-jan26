UPDATE examples
-------------------
Update product price (single document)
-----------------------------

db.product.updateOne(
    { "name": "Laptop" },
    { $set: { "price": 60000 } }
);

db.product.updateOne(
    { "_id": ObjectId("65a7c9e2f1a3b2c4d5e6f789") },
    { $set: { "price": 60000 } }
);


Update multiple products (bulk update)
---------------------------------------

db.product.updateMany(
    { "price": { $lt: 2000 } },
    { $set: { "price": 2000 } }
);

Replace entire document (except _id)
-----------------------------------
db.product.replaceOne(
    { "name": "Mouse" },
    {
        "name": "Wireless Mouse",
        "price": 1200
    }
);

DELETE examples
-------------------
Delete one product
-------------------
db.product.deleteOne(
    { "name": "Printer" }
);

Delete multiple products
---------------------------
db.product.deleteMany(
    { "price": { $gt: 50000 } }
);

Delete all products ( irreversible)
---------------------------
db.product.deleteMany({});

Verify data
-----------------
db.product.find().pretty();



Spring Data Mongodb 
--------------------
MONGODB DOMAIN (MongoRepository)
--------------------
Document
--------------
import org.springframework.data.annotation.Id;
import org.springframework.data.mongodb.core.mapping.Document;
import java.math.BigDecimal;

@Document(collection = "product")
public class Product {

    @Id
    private String id;   // MongoDB ObjectId → String

    private String name;
    private BigDecimal price;

    // getters/setters
}

Repository
import org.springframework.data.mongodb.repository.MongoRepository;
import java.math.BigDecimal;
import java.util.List;

public interface ProductRepository extends MongoRepository<Product, String> {
    List<Product> findByName(String name);
    List<Product> findByPriceGreaterThan(BigDecimal price);
    List<Product> findByPriceBetween(BigDecimal min, BigDecimal max);
}

Custom Mongo Query (example)

import org.springframework.data.mongodb.repository.Query;

Give me all products whose price is less than the value I pass to the method.
------------------------------------------------------------------------
@Query("{ price: { $lt: ?0 } }")
List<Product> findCheapProducts(BigDecimal price);

Products with price greater than the given value

Products priced between min and max (inclusive).
Price between range
-----------------------------------------

What you should remember
--------------------
	JPA → SQL DB only
	MongoRepository → MongoDB only
	@Entity ❌ with Mongo
	@Document ❌ with JPA
	id → Integer/Long for JPA
	id → String for MongoDB
